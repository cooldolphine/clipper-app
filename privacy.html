Privacy policy

Clipper is a personal tool used only by its owner to upload the owner’s own video clips to the owner’s own YouTube channel.

It uses Google sign-in with the YouTube upload permission for that single purpose. It does not collect, store, sell or share data about any other person.

The sign-in token is stored as an encrypted secret in the owner’s private GitHub settings and is never shown publicly.

Contact: the owner of this GitHub account.
